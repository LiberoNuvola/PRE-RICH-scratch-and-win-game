# Code of Conduct

## Our commitment

PRE-RICH is intended to be an open protocol developed through public review, experimentation, and community contribution.

We are committed to maintaining a project environment where people can participate constructively regardless of experience level, background, or role.

## Expected behavior

Participants are expected to:

- communicate respectfully and in good faith;
- focus criticism on ideas, implementations, evidence, and decisions rather than people;
- welcome technical disagreement;
- distinguish evidence from assumptions;
- disclose relevant conflicts of interest where appropriate;
- respect security and responsible-disclosure practices;
- avoid harassment, intimidation, discrimination, or personal attacks.

## Unacceptable behavior

Unacceptable behavior includes:

- harassment or targeted personal attacks;
- discriminatory or hateful conduct;
- threats or intimidation;
- deliberate publication of private or sensitive information;
- malicious disruption of project infrastructure;
- knowingly presenting false technical or security claims as established facts.

## Enforcement

Project maintainers may remove or moderate contributions that violate this code of conduct and may restrict participation where necessary to protect the project community.

For serious or sensitive concerns, contact the maintainers privately through the project's GitHub channels.

## Scope

This code applies to project repositories, discussions, issues, pull requests, and other project spaces maintained for PRE-RICH development.
