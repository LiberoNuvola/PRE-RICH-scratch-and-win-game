# IMMORTAL Economic Kernel

**Scope:** generic mathematical/economic kernel; no blockchain or application-specific constants.

## 1. State

An implementation must represent or derive the quantities needed to evaluate:

```text
EconomicState
Obligations
UnresolvedExposure
ProtectedCapital
ExecutableEconomicValue
AdmissibleActions
HistoricalState
```

## 2. Protected capital

Protected capital contains every amount that cannot safely be treated as discretionary.

```text
RawSurplus = max(0, EEV − ProtectedCapital)
```

## 3. Effective liquidity

A generic executable balance may be represented as:

```text
EffectiveLiquidity = EEV − ProtectedObligations
```

The applicable specification defines ProtectedObligations. Separately represented components must not be double-counted.

## 4. Exposure

For an economic unit of value `P`, let `B(P)` be the applicable maximum exposure generated by one unresolved unit. Then:

```text
WorstCaseExposure(P,N) = B(P) × N
```

`B(P)` is not universalized here.

## 5. Statistical reserve

Where applicable:

```text
Reserve(N) = N × μ + Z × σ × √N
```

This is a risk model and does not replace deterministic protection unless the applicable specification explicitly makes that equivalence.

## 6. Viability kernel

Let `S` be state, `A(S)` admissible actions, `Ω` uncertainty and `T` the transition function:

```text
K_Ω = { S | ∃ admissible policy : ∀ω ∈ Ω, T(S,a,ω) ∈ K_Ω }
```

## 7. Post-state safety

```text
S --a--> S'
```

Acceptance is based on `S'`, not solely on the pre-state.

## 8. Historical maximum

Where required:

```text
H(t+1) >= H(t)
```

Current operating state and historical state remain distinct.

## 9. Hysteresis

A generic hysteresis controller may use:

```text
activation threshold > suspension threshold
```

Concrete thresholds belong to the application or protocol profile that defines them.

## 10. Conservation

A conforming economic realization preserves obligations, protected liquidity, deterministic transitions, non-discretionary rights, single settlement where applicable, and finality of expired rights.
